# B-02: Rand Stablecoins on Stellar

**Research checked:** 2026-11-13  
**Decision:** Do not use any existing ZAR/ZARP asset in the StockOnChain live demo. The demo asset is the separately issued Testnet-only `mZAR`, labelled `MOCK`.

## Findings

Stellar's public Horizon API returned multiple Mainnet assets with the asset code `ZAR`, and two distinct Mainnet assets with the code `ZARP`, when queried on the date above. An asset code is chosen by its issuer and is not unique across Stellar; an asset's identity is the combination of its code and issuer account. A code match, balance, or trustline count does not establish a stablecoin's issuer identity, fiat reserves, redemption rights, regulatory status, or relationship to a similarly named brand.

Examples returned by Horizon:

| Asset on Mainnet | Horizon metadata / observed status | Finding |
|---|---|---|
| `ZAR:GA2XX3WBDXVD7SBVHDZ6EZOUAYMV5YJJSGRSRVNNYM3Y2DAKXULWRIM6` | No `stellar.toml` URL in the Horizon record; one authorized account at lookup | An on-ledger asset exists, but no issuer identity or backing could be verified from the published metadata. |
| `ZAR:GDYG7OEXT7GO2WOYJKRFMYK6PXQTPFRKO4JSNRRZWE4JM2V6QWQR2QZD` | Horizon points to `lobstr.co`; 591 authorized accounts at lookup | The retrieved LOBSTR `stellar.toml` lists different `ACCOUNTS` and does not list this issuer key. This does not verify the issuer relationship or rand backing. |
| `ZARP:GACWH5TUEAZV4VTC44WVJ2P2NCNUDDRBM4NRLB75IWPLZOIANTIMCL7P` | Horizon points to `mintsoroban.org`; two authorized accounts at lookup | A Mainnet asset exists, but its issuer metadata could not be retrieved during this check, so its identity, backing, and connection to a real-world issuer are unverified. |
| `ZARP:GBUU2KM3CSPWEJAD56SY67JOJFU5IA6Z2QGPZBHHOZ5IABK5WJURYCGT` | Horizon points to `stablecoin.cfd`; three authorized accounts at lookup | A Mainnet asset exists, but its identity and backing are unverified. The domain/asset-code combination is not proof of affiliation with a real issuer. |

**Conclusion:** This check did not establish a real, verifiably backed rand stablecoin issued on Stellar. It did establish that multiple unrelated or unverified assets use the `ZAR`/`ZARP` codes. Treat them as unverified, not as evidence that a real rand stablecoin is available. Horizon results are network facts, not reserve attestations; the issuer remains responsible for accurate claims in its Stellar info file.

The official South African business at [zarp.co.za](https://zarp.co.za/) describes ZARP as a seed and agricultural-input distributor, not as the issuer of the Stellar `ZARP` assets above. No relationship between that business and either Horizon issuer was established.

## Demo rule

- Never connect the application to a Mainnet `ZAR` or `ZARP` issuer, use one as a funding source, or present one as the demo balance.
- Only the Testnet Anchor-sim account issues this project's `mZAR` asset. The API asserts the exact Stellar Testnet network and passphrase at startup.
- The frontend and SEP-1 metadata label the token `MOCK mZAR` and state that it has no fiat reserves or redemption. The faucet is a rate-limited Testnet demonstration, not a SEP-24 anchor or deposit service.
- Do not infer price parity or financial value from the UI's rand formatting.
