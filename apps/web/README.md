# StockOnChain Web Application (Next.js PWA)

This package contains the Next.js Progressive Web App (PWA) for **StockOnChain**.

## Features Planned
- PWA offline-first mobile and desktop experience
- Soroban wallet integration (Freighter / Passkey / xBull)
- Stokvel Pot contribution and dividend distribution dashboard
- Multi-role actions (Admin, Issuer, Dealer, Custodian, Sponsor)
